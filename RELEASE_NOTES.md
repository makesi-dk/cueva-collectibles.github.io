# CUEVA Collectibles — V3

## What changed
- Rebuilt the storefront homepage around a dense, familiar retail marketplace structure inspired by major ecommerce conventions.
- Enlarged product tiles and image areas so products are clearly visible instead of tiny thumbnails.
- Changed the featured catalog to a four-column desktop grid with larger square product photography.
- Fixed the CUEVA logo presentation so it is contained instead of cropped.
- Added a cleaner utility/header/search/navigation hierarchy.
- Kept product photography local and separated from page text/UI.
- Preserved the CUEVA dark navy, red, and gold identity rather than copying Amazon branding.
- Kept the complete cart, wishlist, search, product detail, shop, support, and responsive functionality.

## Reference
The layout direction was informed by current ecommerce storefront conventions: prominent search, category navigation, compact product grids, clear product cards, and focused shopping actions.

## Status
Production-ready static demo for GitHub Pages.
